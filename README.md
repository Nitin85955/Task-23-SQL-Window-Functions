# Task 23 – SQL Window Functions Intro

## Overview
This project demonstrates the use of SQL Window Functions
for ranking, sequencing, comparison, and trend analysis.

## Functions Used
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()

## Dataset
Northwind Database

## Tools
- SQL
- MySQL
- GitHub

## Project Work
1. Row numbering of customer orders
2. Product price ranking
3. RANK vs DENSE_RANK comparison
4. Category-wise ranking
5. Top 3 products per category
6. Previous order analysis using LAG()
7. Customer sales ranking
8. Monthly sales trend analysis

## Files
- task23_window_functions.sql
- Task_23_SQL_Window_Functions_Detailed_Report.pdf
- screenshots/

## Key Learning
Window functions allow analytical calculations across
related rows without collapsing the result into a single row.
